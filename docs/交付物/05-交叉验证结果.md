# 交叉验证结果

> 数据源：`new_Data/` 15 家 A 股公司 FY2025 年报摘要（md + PDF 原件）
> 运行：`python create_data/build_index.py --sqlite`
> 本文只覆盖结构化入库（SQLite），文本切分进 Milvus 未运行。

---

## 一、结论

两条独立的路各读一遍表格，再按 `(指标, 期间)` 对账：

| 结果 | 条数 | 说明 |
|---|---|---|
| 两路一致（`both`） | **665** | 同一指标同一期间，两路读出的数完全相同 |
| 仅 OCR（`ocr`） | **15** | 15 家的股东总数，kv 文本不是表格，不在裁图里 |
| 仅 VLM（`vlm`） | **0** | 没有「只有模型读到、规则漏掉」的数据 |
| **冲突（`conflict`）** | **1** | 两路都读到但对不上，不入库 |
| **最终入库** | **680** | 681 − 1 条冲突 |

一致率 **665 / 681 = 97.7%**。

---

## 二、方法

```
每份财报
  ├─ OCR 路  md 里的 HTML 表格 → 网格展开 / 多组表头 / 断行修复 → 规则取数
  └─ VLM 路  PDF → find_tables() 检出表格 bbox → 裁图（跨页拼接）→ 视觉模型读数
                    ↓
       按 (metric_code, period_label) 配对
                    ├─ 一致      → source = both
                    ├─ 仅一路    → source = ocr / vlm
                    └─ 不一致    → 写入 fact_conflict，**不入 fact**
```

三点关键设计：

- **配对靠语义键，不靠位置**。md 的表序号和 PDF 的页码表序是两套编号，硬映射只会引入新错误；`(指标, 期间)` 本身就能唯一确定一条事实。
- **比换算成元之后的 `value_yuan`**，不比原单位数值。一份摘要通常只有一个货币单位（中芯国际、宁德时代是千元，其余是元），由代码从 md 取出写进 prompt，不让模型从图里猜。
- **单位与时点由代码定，不采信模型**。`point_in_time` 指标强制「年末」，避免跨页表的下半页没有表头时模型把「2025年末」读成「2025年」。

## 四、唯一一条冲突

```
公司      华海清科
指标      ocf_net（经营活动产生的现金流量净额）
期间      2025Q3
OCR       29,519,005.37
VLM       29,510,005.37      ← 把 9 看成了 0
```

**判定依据**：打开原图（`new_Data/华海清科/tables/p13_t2.png`）人工核对，表里写的是
**29,519,005.37**，OCR 正确、VLM 错。

**处理**：该条写入 `fact_conflict` 表，不进 `fact` 表。所以华海清科入库 49 条而不是 50 条。

这就是交叉验证的目的 —— 这条如果只跑 VLM，会静默入库一条错数据；只跑 OCR，
则永远不知道模型会错。两路一起跑，错的会被拦下。

## 五、附：C1 恒等式校验

对账之外还有一道独立校验：**2025 年四季度之和必须等于 2025 年度值**（容差 1）。

```
15 家 × 营收 / 净利润 / 经营现金流 = 45/45 通过
```

列错位、单位错乱、数字截断都会让这个等式不成立。

## 六、复现

```bash
# 全量：裁图（若 tables/ 为空）+ VLM 读数（无缓存时）+ 对账 + 入 SQLite
python create_data/build_index.py --sqlite

# 只想看解析结果不写库
python create_data/build_index.py --dry-run

# 重新生成某家的表格图（改过裁图逻辑后需先删 tables/）
python -m create_data.vlm_extract new_Data/中芯国际

# 查看冲突明细
sqlite3 db/financial.db "select * from fact_conflict"
```

**注意**：`vlm_facts.json` 是模型读数缓存，命中时不会调用模型。想强制重跑，
先删掉 `new_Data/<公司>/vlm_facts.json`。若怀疑某条读错，直接改这个 json 即可，
不用重裁图、不用重新调模型。
